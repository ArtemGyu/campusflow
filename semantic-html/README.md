# Help Desk — практическая работа №2

Откройте index.html в браузере. Сборка и доступ к интернету не нужны.

## Состав

- index.html — список обращений, история статусов, справка и FAQ.
- create-ticket.html — форма создания обращения.
- ticket-101.html, ticket-102.html, ticket-103.html — страницы обращений.
- assets/css/styles.css — общие адаптивные стили.
- assets/js/form.js — проверка учебной формы и выбор контактных данных.
- assets/images/support.svg — иллюстрация поддержки.

Форма учебная: данные проверяются в браузере и не отправляются на сервер.

Использованы Grid/Flexbox, border-box, ограниченный контейнер, CSS-переменные, min() и clamp(). Длинные строки переносятся; высота текстовых карточек определяется содержимым.

Макет разработан самостоятельно по согласованию с пользователем. Проверено 18 сценариев; максимальное отклонение проверенных размеров и координат — 2,45 px при viewport 1440 × 1400.

broken.html и fragment-fixed-sr.html — исходные учебные примеры предыдущей работы, в интерфейс не включены. Отчёт и скриншоты хранятся локально и в репозиторий не загружаются.
